# Колер / Koler

Пипетка для Windows 10/11 x64, локальные библиотеки цветов и ведомости материалов для строительных объектов.

**[Скачать последнюю сборку](https://github.com/CrazzyHedg17/Koler/releases/latest/download/Koler-Windows-x64.zip)** · [Изменения](https://github.com/CrazzyHedg17/Koler/releases/latest)

Распакуйте ZIP и запустите `Koler/Koler.exe`. .NET и Microsoft Office устанавливать не нужно.

- Системная пипетка поверх обычных приложений: Ctrl+Shift+C, Enter — выбрать, Esc — отменить.
- RGB, HEX, HSL, приблизительный CMYK; ближайшие соответствия RAL Classic, RAL Design, RAL Effect, NCS и PANTONE.
- Традиционные цвета Санкт-Петербурга по сохранённым материалам КГА.
- Дневная и тёмная темы, история, избранное, импорт CSV/ASE/JSON.
- Объекты строительства → материалы → выбранные цвета с названием палитры и кодом.
- Оформленные ведомости JPG и Word (DOCX).

9324 образца встроены в EXE. Пипетка, палитры, объекты и экспорт работают без сети. Только проверка и загрузка обновлений обращаются к GitHub; автоматическую проверку можно отключить в настройках.

Палитры — приблизительные цифровые снимки сторонних источников, а не лицензированные физические эталоны. NCS в поставке содержит 1952 образца. Для окончательного подбора материала используйте реальный образец. Источники, лицензии и контрольные суммы включены в ZIP.

Личные данные: `%LOCALAPPDATA%/Koler`. Для резервного копирования закройте приложение и скопируйте эту папку. Обновление не заменяет объекты, историю и пользовательские библиотеки. Перед установкой проверяются SHA-256 и версия; предыдущие файлы сохраняются для отката.
